# 개인용 한글 해외주식 관리 프로그램 개발 프롬프트

## 목표
개인용 한글 해외주식 관리 프로그램을 만든다. 대상 시장은 미국, 중국 A주, 홍콩이며 사용자는 나 혼자다.

## 필수 기능
1. 관심종목 관리
   - 종목코드나 이름으로 검색해 추가한다. 예: AAPL, 600519, 00700
   - 목록에서 삭제한다.
   - 목록은 로컬 SQLite에 저장해 프로그램을 다시 열어도 유지된다.
   - 목록에 종목명(한글명이 있으면 한글명), 시장, 현재가, 등락률을 보여 준다.
2. 재무제표 확인
   - 종목을 선택하면 손익계산서, 재무상태표, 현금흐름표를 연간과 분기로 보여 준다.
   - 최근 5년(분기는 8개)을 표로 보여 주고, 주요 항목은 그래프로도 보여 준다.

## 데이터 출처 (무료, 개인 사용)
- 미국 재무제표: SEC EDGAR companyfacts API
  - User-Agent 헤더에 이름과 이메일을 넣는다.
  - 초당 10회 이하로 호출한다.
- 미국 시세: Finnhub 무료 API
  - API 키는 .env 파일에서 읽는다.
  - 분당 60회 이하로 호출한다.
- 중국·홍콩 재무제표와 시세: AKShare
- 모든 응답은 로컬에 캐시한다. 재무제표는 하루, 시세는 1분 동안 재사용한다.
- 호출에 실패하면 화면에 한글 안내를 띄우고, 마지막으로 받은 값과 그 시각을 보여 준다.

## 한글화
- 메뉴, 버튼, 표 제목, 오류 메시지를 전부 한글로 쓴다.
- 재무 항목 대응표(mapping.json)를 만든다.
  - 예: Revenues→매출액, NetIncomeLoss→당기순이익, 营业收入→영업수익
  - 주요 항목 100개 이상을 넣는다.
  - 대응표에 없는 항목은 원문 그대로 보여 준다.
- 종목 한글명 사전(names_ko.json)을 둔다. 사용자가 직접 추가하고 고칠 수 있게 한다.
- 숫자 형식
  - 금액은 원래 통화로 표시하고 단위는 백만으로 한다.
  - 천 단위마다 쉼표를 찍는다.
  - 날짜는 YYYY-MM-DD로 쓴다.

## 기술 조건
- 언어와 화면: Python 3.11 이상, 화면은 Streamlit
- 데이터베이스: SQLite
- 구조: 데이터 수집, 한글화, 화면을 모듈로 분리한다. 나중에 출처를 바꾸기 쉽게 하기 위해서다.
- 실행: `pip install -r requirements.txt` 후 `streamlit run app.py` 한 줄로 실행되게 한다.
- 문서: 설치 방법, 키 설정, 사용법을 README에 한글로 쓴다.
- 금지: AGPL 코드(Ghostfolio, Wealthfolio)는 복사하지 않는다. 비공식 수집 도구인 yfinance도 쓰지 않는다.

## 완료 기준
- AAPL, 600519, 00700을 추가했다 삭제할 수 있다.
- 세 종목의 재무제표가 한글 항목명으로 표시된다.
- 출처별 수집 함수의 테스트 코드가 통과한다.
